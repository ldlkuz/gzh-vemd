Mermaid · 图谱

一张图，一种语言。

把数据、流程与关系画出来——从简单的流程图到桑基曲线。这里是 Mermaid 全部图表类型的陈列。

17 类图表 每张可切换「渲染 / 源码」 Mermaid v11
流程图 时序图 类图 状态图 ER 图 甘特图 饼图 四象限 需求图 Git 图 C4 思维导图 时间线 旅程图 柱状·折线 桑基图 块状图

按图往下翻，或点顶部导航直达。每张图右下角可切换到对应语法源码——复制进支持 Mermaid 的编辑器即可复用。

01

流程图

flowchart · graph

方向与分支——最常用的一类。`graph TD` 自上而下，`LR` 自左向右。

graph TD A[开始] --> B{登录成功?} B -- 是 --> C[进入控制台] B -- 否 --> D[提示错误] C --> E[记录日志] D --> E
02

时序图

sequenceDiagram

参与者之间的消息往来，适合接口调用、业务流程。

sequenceDiagram participant U as 用户 participant API as 服务 participant DB as 数据库 U->>API: 提交订单 API->>DB: 锁定库存 DB-->>API: 成功 API-->>U: 下单完成
03

类图

classDiagram

面向对象的结构与继承关系。

classDiagram class 动物 { +String 名称 +void 呼吸() } class 狗 class 猫 动物 <|-- 狗 : 继承 动物 <|-- 猫 狗 : +void 吠()
04

状态图

stateDiagram-v2

对象或流程的状态流转。

stateDiagram-v2 [*] --> 待处理 待处理 --> 处理中: 开始 处理中 --> 已完成: 成功 处理中 --> 已取消: 超时 已完成 --> [*] 已取消 --> [*]
05

ER 图

erDiagram

实体与关系的实体关系图，常见于数据库建模。

erDiagram CUSTOMER ||--o{ ORDER : 下单 ORDER ||--|{ ORDER_ITEM : 包含 PRODUCT ||--o{ ORDER_ITEM : 被包含 CUSTOMER { int id string name } ORDER { int id string status }
06

甘特图

gantt

时间轴上的任务排期与依赖。

gantt title 上线计划 dateFormat YYYY-MM-DD section 准备 需求调研 :a1, 2024-06-01, 7d 原型设计 :after a1, 5d section 开发 前端开发 :2024-06-10, 10d 后端开发 :2024-06-10, 10d section 发布 联调验收 :2024-06-22, 5d 正式上线 :2024-06-28, 2d
07

饼图

pie

占比构成，一眼看分布。

pie showData title 流量来源占比 "自然搜索" : 45 "直接访问" : 28 "外链" : 17 "社媒" : 10
08

四象限图

quadrantChart

把对象散进两轴四象限，用于优先级、价值评估。

quadrantChart title Priority Guide x-axis Low --> High y-axis Low --> High quadrant-1 Keep quadrant-2 Trim quadrant-3 Invest quadrant-4 Avoid Core : [0.82, 0.20] Chance : [0.65, 0.70] Noise : [0.25, 0.90]
09

需求图

requirementDiagram

需求、元素与验证关系的建模。

requirementDiagram requirement req_login { id: 1 text: "用户需通过登录验证" risk: medium verifymethod: test } element auth_svc { type: system } auth_svc -satisfies -> req_login
10

Git 图

gitGraph

提交与分支合并的可视化。

gitGraph commit branch feature commit commit checkout main commit merge feature commit tag: "v1.0"

C4 上下文

C4Context · C4Container

C4Context title 系统上下文 Person(user, "访问者") System(web, "门户网站") SystemDb(db, "数据库") Rel(user, web, "浏览 / 提交") Rel(web, db, "读写数据")
